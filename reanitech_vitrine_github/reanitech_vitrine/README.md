# Réani'Tech — site vitrine

Site vitrine statique en HTML, CSS et JavaScript, prêt à publier avec GitHub Pages.

## Avant publication

1. Remplace `[Ta ville]` dans `index.html` par ta zone réelle.
2. Dans `script.js`, remplace `REMPLACE-MOI-PAR-TON-EMAIL` par l'adresse e-mail professionnelle que tu souhaites afficher.
3. Remplace le logo typographique provisoire par ton logo réel (si tu m'envoies le fichier, je peux l'intégrer).
4. Vérifie toutes les prestations et ne conserve que celles que tu es réellement en mesure de proposer.
5. Ajoute les informations légales et de confidentialité adaptées avant de mettre le site en ligne pour une activité commerciale.

## Publier avec GitHub Pages

1. Crée un dépôt GitHub, par exemple `reanitech`.
2. Envoie les fichiers `index.html`, `style.css`, `script.js` et `README.md` à la racine du dépôt.
3. Dans le dépôt, ouvre **Settings → Pages**.
4. Dans **Build and deployment**, choisis **Deploy from a branch**.
5. Sélectionne la branche `main` et le dossier `/ (root)`, puis clique sur **Save**.
6. Attends la publication : GitHub affichera l'adresse du site dans la section Pages.

## Fonctionnement du formulaire

Le formulaire actuel ouvre le logiciel de messagerie du visiteur avec un message prérempli. Il ne stocke ni n'envoie automatiquement les données. Pour recevoir les demandes directement depuis le site, il faudra ensuite connecter un service de formulaire ou un backend sécurisé.

## À savoir

GitHub Pages héberge des sites statiques. Il ne fournit pas de traitement serveur pour les formulaires, les devis ou les données clients.
